# Installer UniSchema sur Android (tablette ou téléphone)

Adresse de l'app : **https://bolz002.github.io/schema-unifilaire/**

Aucun compte, aucune clé, aucun serveur à lancer : l'app est publiée sur GitHub Pages.

## Installation

1. Ouvrir l'adresse dans **Chrome** (connexion internet nécessaire la première fois).
2. Menu **⋮** → **Installer l'application** (ou **Ajouter à l'écran d'accueil** → **Installer**).
3. Lancer **UniSchema** depuis l'icône éclair : plein écran, sans barre d'adresse. L'app apparaît aussi dans la liste des applications d'Android.
4. Ouvrir l'app une première fois avec du réseau et attendre quelques secondes : tout est mis en cache.

## Vérifier le mode hors ligne

Activer le **mode Avion**, fermer l'app, la rouvrir : elle doit s'ouvrir normalement, avec le badge « Hors ligne ». Les schémas sont enregistrés sur la tablette.

## Mises à jour

À chaque nouvelle version publiée, un bandeau **« Nouvelle version disponible → Recharger »** apparaît au lancement suivant (avec réseau). Rien n'est rechargé sans votre accord.

## Sauvegarde

Les schémas restent sur l'appareil. Exporter régulièrement les `.eds` (menu **Fichier** → Enregistrer) vers Drive, OneDrive ou par mail.

**Attention** : la version installée depuis le serveur local (`desktop-bol…:8443`) et la version publiée sont deux apps distinctes, avec leurs propres données. Enregistrer les `.eds` de la version locale, puis les rouvrir dans la version publiée. Désinstaller ensuite la version locale pour éviter la confusion.

## Désinstaller

Appui long sur l'icône → **Désinstaller** (ou Paramètres → Applications → UniSchema).
